------------------------------

Use this app as an example of what you can do with GenAI in your own project.

The majority of the showcase examples in this app follow the principles from the [GenAI Commons](https://marketplace.mendix.com/link/component/239448), [Agent Commons](https://marketplace.mendix.com/link/component/240371) and [Conversational UI](https://marketplace.mendix.com/link/component/239450) modules. This means that these example use cases are automatically compatible with other GenAI connectors that follow these principles. In this app you can see how you can build vendor-agnostic GenAI use cases that integrate with operations from (for example) the [Mendix Cloud GenAI Connector](https://marketplace.mendix.com/link/component/239449), [OpenAI Connector](https://marketplace.mendix.com/link/component/220472), [Amazon Bedrock Connector](https://marketplace.mendix.com/link/component/215042), [Mistral Connector](https://marketplace.mendix.com/link/component/248276) as well as the [Google Gemini Connector](https://marketplace.mendix.com/link/component/254741) at the same time.
